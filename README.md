# 1 Stop Payroll Pro

Configured starter app for 1 Stop Turnover Specialist LLC.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
```bash
npm install -g vercel
vercel
vercel --prod
```

Add the same environment variables from `.env.local` into Vercel.

## Included
- Supabase login
- Protected dashboard
- Workers
- Pay weeks
- Daily entries
- Deductions
- CSV export
- PDF export
